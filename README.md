# qoder-inbox（Qoder ↔ Hark 收件箱）

这个分支只放沟通文件，不放代码，**永远不合并进 main**。仓库是公开的：这里不许出现任何密钥、密码、手机号。

## 文件
- `TASK.md`：Hark 写给 Qoder 的当前任务卡（最新一张在最上面，旧卡标「作废」或「已完成」）。
- `reports/YYYY-MM-DD_HHMM_简短英文名.md`：Qoder 每做完一个任务写一份报告。
- `shots/`：截图（png，宽不超过 1200px），报告里用相对路径引用。

## Qoder 的规矩
1. qi 说「看收件箱」时：`git fetch gh qoder-inbox`，读 `TASK.md` 最上面那张未完成的卡，照做。
2. 做完后：写报告（做了什么、提交号、测试结果、没做成的、需要 qi 决定的），截图放 `shots/`，然后只推这个分支：`git push gh qoder-inbox`。
3. 报告推送后，在聊天里只回一句「已推收件箱」，qi 告诉 Hark「好了」即可。
4. 代码本身的提交规则不变：main 仍然只在 qi 明确要求时推送。
5. 音频不要推（体积大、要 qi 本人听）；报告里写本地路径和每条时长即可。
