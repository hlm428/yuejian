## 测量与测试结果

以下是此前试音任务实际执行的验证；本次收件箱测试不重新调用配音接口。

- 时长：按最终 MP3 解码得到的 PCM 采样数计算，排除 MP3 编码填充。
- 字数：只计处理后的汉字，不计标点、提示和情绪标签；用未四舍五入的比值判断是否在 4.5–5.5 汉字/秒内。
- 静音：使用 −50 dB 阈值和 10 ms RMS 窗；句中停顿超过 0.5 秒即拒绝，不通过剪短停顿伪造合格。
- 离线检查通过：文本清理、字数、五句来源与情绪配额、相同请求描述与单标签、每句最多四次请求、达标即停、失败状态展示与 HTML 转义。
- 合成音频验证：人工构造的 0.6 秒内部静音被保留并判为不合格；短首尾静音不变，过长首尾静音按规则裁剪。
- 五条最终样本均可解码，复算数值与记录一致，种子和来源数据校验值未变，选中音频校验值匹配记录。
- 独立 ffmpeg 静音检测在五条选中样本中均未发现达到 0.5 秒的停顿；但是五条语速均低于 4.5，语速验收仍全部失败。
- 浏览器已验证本地 HTTP 与 file 直接打开：五条均能播放至结束，暂停/恢复及互斥切换正常；本地 HTTP 下五条音频请求均为 200，无控制台错误。
