## 1. 一句话：这游戏好玩在哪

夜里打开，看看月见公寓哪扇窗还亮着，进去陪她一会儿。

**她会记住你做过的事，你的出现会改变她的房间和她说的话。**

这不是"点一点涨数值"的点击器，是"住在同一栋楼里、慢慢变熟"的关系模拟。好玩的三个点：

1. **她记得**——昨天你送了咖啡，今天她说"第二杯了，你是想让我通宵？"
2. **房间变了**——你送的东西出现在她桌上，你的杯子出现在她房间。
3. **关系变了**——从"别戳"到"你又来了"，再到"今天有点安静"，最后她主动发消息问你在哪。

## 2. 核心循环：玩家一天玩什么

```
打开游戏 → 看哪扇窗亮着 → 点窗 → 看她在干嘛 → 点"拜访"进房间
→ 大立绘站着，戳 / 喂 / 聊 → 亲密度涨
→ 点具体互动 → 触发一段剧情（两个小人演，你能互动）
→ 看一眼手机（她给你发消息了吗）→ 看一眼今日小事 → 关掉
→ 第二天回来：她记得昨天，你的房间多了点东西，猫可能在门口等你
```

- **一次会话 5–10 分钟**，不逼玩家长待。
- **每天有新东西**：今日小事刷新、她的话变了、可能有新消息、可能触发新剧情。
- **没有失败**：没有体力、没有倒计时、没有惩罚。错过就错过，碎片可以之后再触发，生日 3 天内可补过。

## 3. 第一分钟：新手引导（决定留不留人）

第一次打开，3 步，不超过 2 分钟，可以跳过：

1. **夜澜给你钥匙**——她站在门口（大立绘），一句台词："302，你的房间。租金……便宜点算了。"（伏笔：你长得像她 几百年前认识的人，不说破。）
2. **你进 302**——放下纸箱，画架立起来。系统提示："你的房间，之后可以在这里接插画稿赚钱。"
3. **敲门声，知夕来了**——她端着一盘刚烤好的马卡龙："新邻居，欢迎哦。"她住 301，就在你隔壁。（伏笔：她是特意搬到你隔壁的，不说破。）

引导结束，停在主界面：一扇窗亮着（401 云笙的台灯）。点它，进房间，戳她一下，她说"无聊"。第一分钟结束，玩家已经会玩了。

## 5. 房间：大立绘站桩（安吉拉式）

进房间先看到的：**她的大立绘站在房间里**，像《我的安吉拉》那样站着，有轻微呼吸起伏（CSS 动画）、偶尔眨眼（表情切换）。

房间里能点的东西：

- **点她本人**：她有反应（表情切换 + 一句台词 + 小跳）。点多了有"戳太多"标签（见 §7）。
- **底部按钮**：戳、喂、聊天、送东西（哄睡只在 22:00–02:00 出现）。
- **点房间物件**（每间 3–4 个热点，1 句反应，便宜又可爱）：
  - 云笙 401：黑咖啡（"续杯？"）、报告纸（"别乱翻"）、推理小说、猫碗（可能引来楼道猫）。
  - 知夕 301：烤箱、马卡龙、草莓蛋糕、心理学书。
  - 曦月 501：钢琴、曲谱、水晶灯、茶具。
  - 夜澜顶层：水晶球、塔罗牌、红色果汁、古董钟。
- **主控永远不露脸**：房间里只出现她的立绘。主控出现在"触发剧情"的小人画面里（背影/侧面）。主控在家不背书包、不穿外出鞋；302 房间里不放主控人。

房间背景用 Hark 的无人版（**已出**：v8 包里 5 张纯背景，无人物、无字）。

## 6. 触发剧情：两个小人演一段故事（游戏的内容本体）

**这是什么**：点一个具体互动，就触发一段 3–5 幕的小剧情，两个小人（她 + 你）在剧情里演，你能互动。没有失败，演完有奖励。

**一场戏的结构**（每场 1–2 分钟）：

| 幕 | 内容 | 玩家做什么 |
|---|---|---|
| 开场 | 她在干嘛，你走进来 | 点一下继续 |
| 发展 | 事情发生（猫跑进来 / 烤箱冒烟 / 她接到电话） | 点一下继续，或二选一 |
| 选择 | 一个小选择，两个选项都对，味道不同 | 选一个（影响一句台词 + 少量亲密度） |
| 结尾 | 她的一句收束台词，呼应你的选择 | 看完，领奖励 |

**奖励**：亲密度 +5~10、一句她记住的话（可能变成记忆标签）、有时房间多个小东西、有时埋一条碎片线索。

**三种触发方式**：

1. **主动选**：房间里点"一起"按钮，从已解锁的列表里选一场。
2. **条件触发**：满足条件自动弹（记忆标签、好感到了、第一次来、半夜来、她过生日）。
3. **随机小事件**：进房间小概率触发（停电、她发烧、猫跟你进门）。

**每人的剧情清单**（先写名字和一句话，内容以后慢慢写）：

- **云笙**：① 深夜加班，你送咖啡 ② 楼道猫跟你回家 ③ 她发烧，你照顾她 ④ 帮她整理报告找文件 ⑤ 出警回来很晚，你在门口等她 ⑥ 她第一次主动说"今天有点安静"。
- **知夕**：① 一起做马卡龙 ② 店里来了怪客人 ③ 她做了便当给你 ④ 她笑着说"没关系哦，我不生气"（占有欲初现） ⑤ 你收到她亲手织的围巾 ⑥ 她问你"如果有人抢走你怎么办"。
- **曦月**：① 陪她练琴，你选曲 ② 她离家出走后第一次做饭 ③ 她教你弹一段简单的曲子 ④ 她嘴硬但给你买了礼物 ⑤ 她在你面前第一次哭 ⑥ 她问你"本小姐弹得怎么样"。
- **夜澜**：① 翻塔罗给你算运势 ② 她带你逛古董店，讲一件古董的故事 ③ 下雨天她终于能白天出门 ④ 她看着你发呆（前世伏笔） ⑤ 她教你跳一支舞 ⑥ 月见祭前夜，她在天台等你。

**内容量**：每人 6 场起步，长期 6–8 场。v0.2 只要云笙的 1–2 场（① 深夜送咖啡 + ② 楼道猫），先证明这个格式好玩。

**小人美术**：每场戏用小人的动作姿态演。需要的动作小人（每人 3–4 个）：工作、睡觉、吃东西、发呆，再加每人 1 个专属动作（云笙蹲地喂猫、知夕端盘子、曦月弹琴、夜澜翻牌）。**先做云笙的**：趴桌写报告、缩床睡觉、蹲地喂猫、窗边发呆。

**姿势参考**：窗内三套动作就是现成的姿势——云笙 A 写报告、C 抱猫，知夕 A 吃蛋糕，曦月 A 弹琴，夜澜 A 举果汁，照着画成 Q 版就行，不用重新设计姿势。

## 7. 记忆标签：她记得你（游戏最值钱的系统）

本地记几个标签，满足条件解锁特殊台词或房间变化。不用 AI，便宜。

| 标签 | 触发条件 | 效果（以云笙为例） |
|---|---|---|
| 常送黑咖啡 | 送黑咖啡 ≥3 次 | "第二杯了。你是想让我通宵？"；之后桌上多一个杯垫 |
| 换了口味 | 连送咖啡后某天改送面包 | "……今天不是咖啡？" |
| 半夜常来 | 22:00–02:00 来过 ≥3 次 | 晚安台词变化 |
| 很久没来 | 48 小时没打开 | 一句淡淡的想念（"……你不来也可以提前说一声。"不是责怪） |
| 记得她不吃甜 | 7 天没送甜食 | 她主动提"你居然还记得我不吃甜的" |
| 戳太多 | 一天戳 >10 次 | 冷脸反应，当天戳不再涨亲密度（第二天恢复，不扣好感） |
| 温柔照顾 | 同一天喂 + 聊 + 哄睡都做了 | 心情大涨 + 一句特别台词 |
| 她给你留东西 | 你连续 3 天来看她 | 第二天 302 门口多一份她留的甜品 / 一张纸条 |

**设计铁律**：标签是"她注意到了"，不是监视和惩罚。想念要淡淡的，不能变成道德绑架；冷脸第二天就恢复，绝不扣好感。

**低成本又有感觉的补充点子**：

- **她给你留东西**（上表最后一行）：单向的关心，不用你做什么，回来就发现门口多了东西。
- **"你画了她"**（见 §13）：你是插画师，画了她的速写会出现在她房间，她会提。
- **称呼变化**：关系到了，她开始叫你专属称呼（不是名字，是"喂"→"你"→ 只有你们懂的叫法，暧昧期再定）。
- **未说完的话**（见 §18）：一场戏结尾她话说一半，"剩下的明天再说"——第二天回来才能听完。

## 8. 好感与关系阶段

阈值已定（SPEC §6）：邻居 0–19 / 朋友 20–49 / 暧昧 50–79 / 恋人 80–100。

**邻居阶段内部也要有小变化**，不能等到 20 才变（这是诊断报告点名的问题）：

| 邻居内阶段 | 亲密度 | 感觉 | 她的典型话 |
|---|---|---|---|
| 初见 | 0–6 | 礼貌、保持距离 | "别戳。" / "放那儿吧。" |
| 熟悉 | 7–13 | 习惯你来了 | "你又来了。" / "咖啡放左边。" |
| 依赖 | 14–19 | 开始等你 | "今天有点安静。" / "你不来也可以提前说一声。" |

**每个阶段看得见的变化**：

| 阶段 | 房间 | 手机 | 解锁 |
|---|---|---|---|
| 邻居 | 她的房间，只有她的东西 | 私信，客客气气 | 戳、喂、私信 |
| 朋友 | 你的杯子、拖鞋出现在她房间 | 朋友圈，开始点赞你的动态 | 朋友圈、哄睡、碎片开始掉 |
| 暧昧 | 她主动发消息、等你；你的速写出现在她桌上 | 她主动找你，半夜的消息 | 约会、修罗场、换装 |
| 恋人 | 天台、纪念日、专属称呼 | —— | 月见祭天台结局 |

**数值（提案，任务 3 再细化）**：戳 +1、喂（喜欢）+3 / （最爱）+5、聊天 +2、送礼物（最爱 +15 / 喜欢 +8 / 普通 +3 / 讨厌 +0 且心情 −10，SPEC §10 已定）、触发剧情 +5~10。**每天软上限约 20**：超过后涨得变慢，她说一句"今天已经很开心了，明天再来吧"——不是硬墙，是让她"累了"，保护台词不被一天刷完。按这个速度，一个女主从 0 到 100 大约要一个月每天玩一会儿，正好。

**心情**：0–100，现在开不开心。好心情时亲密度涨得快（×1.5），坏心情时涨得慢（×0.5）。被忽视、吃醋、收到讨厌的礼物只掉心情，**永远不扣亲密度**（SPEC §7 已定）。

饱食、精力、寂寞先放后台或不做（v2 已定）。寂寞尤其慎重，不能变成道德绑架。

## 9. 手机：她会主动找你

分三步做，先只做私信：

1. **私信（阶段 B）**：她按自己的日程和状态给你发消息。饿了（"冰箱空了，无聊。"）、加班完了、下雨了、看到一只猫。你回 2–3 个预设选项，每个味道不同，少量亲密度。红点 = 打开游戏的理由。
2. **朋友圈（阶段 C）**：她发动态，你点赞 / 预设评论。**四个人会互相评论**：曦月和云笙斗嘴、夜澜逗曦月、知夕给所有人点赞——她们的关系在这里看得见。
3. **群聊 + 电话（以后）**：群聊是文字量黑洞，往后放。

手机也是"今日小事"和生日/节日提醒的入口。

## 18. 让玩家第二天回来的钩子（留存）

这是游戏生死线。五个钩子，按强度排：

1. **"未说完的话"（最强）**：一场戏结尾，她话说一半，"剩下的，明天再说。"第二天回来才能听完。这是字面意义上的"明天再来"。
2. **她主动找你**：第二天早上打开，手机里有她昨晚发的消息（根据你昨天做的事写：你送了咖啡 → "昨天的咖啡很好喝"；你 48 小时没来 → "……你不来也可以提前说一声。"）。
3. **猫和今日小事**：猫可能在门口等你，今日小事刷新了。
4. **离线变化**：你不在的时候，她的房间变了一点（杯垫多了、速写贴上了、猫睡在她床边）。
5. **收藏进度**：卡面 / 碎片 / 速写差一张就齐了，相册里看得见。

**反模式**：绝不用"再不回来她会难过 / 好感会掉"吓唬玩家。想念要淡淡的，回来是开心的，不是赎罪的。

## 25. 回答 v2 文档的 5 个问题

1. **外观主界面 + 点窗进房间，有没有更好的做法？** 有，两个小补强：① 窗内真人三套动作，每进游戏随机抽一套，楼立刻"活了"；② 点窗的目标要大（整扇窗 + 光晕都能点），手机上好点。天台、便利店、入口大厅、古董店也能点（商店以后开，天台锁着留伏笔）。
2. **阶段 A 的范围是不是够小、够精？** 再砍一刀：外观 + 云笙房间 + 戳 / 喂 / 聊 + 2 个数值 + 存档 + **1 场触发剧情**。其余三人窗户正常显示人物，但点开卡片后"拜访"未解锁。
3. **记忆标签和礼物摆放，还有什么低成本又有感觉的点子？** 三个：① 她给你留东西（门口多一份甜品 / 一张纸条）；② "你画了她"（速写出现在她房间）；③ "未说完的话"（一场戏结尾话说一半，第二天才能听完）。
4. **四个专属玩法哪个最值得先做？** 云笙的整理报告（纯点选，最便宜）→ 夜澜的塔罗（翻牌 + 文案）→ 知夕的做甜品（顺序逻辑）→ 曦月的练琴（节奏最难调，放最后）。
5. **有没有让玩家"第二天想回来"的更好钩子？** "未说完的话" + "她主动找你"（第二天早上手机里有她按你昨天的行为写的新消息）。这两个比任何奖励都强，因为是她想你，不是系统催你。
