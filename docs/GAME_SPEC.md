## 1. 定位（来源 §2.1）

百合向、女性向养成小游戏，玩法类似《我的安吉拉》：照顾、互动、攒好感。**没有主线剧情**，只有日常和慢慢变近的关系。网页小游戏，手机电脑都能玩。

## 2. 玩家（主控）（来源 §2.2）

- 女生，302 新房客，自由插画师。
- 无脸主控：只出现背影、身材或鼻子以下，永远不画脸。
- 形象：栗棕色及肩长发，米色宽松毛衣，浅蓝直筒牛仔裤，白帆布鞋，小双肩包。（按立绘参考图：美术资产 > 定稿设定）
- 开局填昵称（不填默认叫「你」）和生日，私信和卡面小故事里用这个昵称。

## 5. 核心循环（来源 §2.4）

打开游戏 → 公寓外观（按手机真实时间亮灯）→ 游戏内手机红点（私信、朋友圈、群聊、电话）→ 进她房间互动（戳、喂、聊天）涨好感 → 点具体互动触发剧情 → 碰隐藏条件掉秘密碎片 → 好感到档解锁卡面、关系升级。

## 6. 关系阶段（阈值：好感 0 / 20 / 50 / 80，v1 实测可调）（来源 §2.5）

| 阶段 | 好感 | 解锁 |
|---|---|---|
| 邻居 | 0–19 | 戳、喂、私信 |
| 朋友 | 20–49 | 朋友圈、哄睡，碎片开始掉 |
| 暧昧 | 50–79 | 约会、修罗场、换装 |
| 恋人 | 80–100 | 月见祭天台结局 |

邻居阶段内部也要有小变化，不能等到 20 才变（v3.2 §8，qi 已定）：

| 邻居内阶段 | 亲密度 | 感觉 | 她的典型话 |
|---|---|---|---|
| 初见 | 0–6 | 礼貌、保持距离 | 「别戳。」/「放那儿吧。」 |
| 熟悉 | 7–13 | 习惯你来了 | 「你又来了。」/「咖啡放左边。」 |
| 依赖 | 14–19 | 开始等你 | 「今天有点安静。」/「你不来也可以提前说一声。」 |

- **每天亲密度软上限 20（qi 已定）**：超过后继续互动只涨一半，她说一句「今天已经很开心了，明天再来吧」——不是硬墙，是让她「累了」，保护台词不被一天刷完。
- 哄睡：阶段 A 不做；阶段 B 起按朋友阶段解锁（限 22:00–02:00）。

## 7. 状态需求（来源 §2.6）

- 阶段 A 只做心情 + 亲密度；饱食、精力、寂寞先放后台或不做（以后再说）。
- **吃醋、寂寞只掉心情，不扣好感。**

## 9. 经济（来源 §2.8）

- 货币：**月光币**。
- 赚钱：每天 2–3 个插画稿（配色、构图小游戏，30 秒一局）；四人约稿（曦月演奏会海报、知夕甜品菜单、夜澜古董画、云笙嫌疑人画像），给得多还涨好感。
- 今日小事（公寓便签）：每天 2–3 条，写成小故事，做完给少量月光币，不做不罚。
- 每日登录 10 月光币，累计来 7 天多给一个限定小物（不用连续，不算断签）。
- 商城 = 公寓楼下便利店：食物（补饱食）、礼物（涨好感，会摆进她房间）、衣服（主控换装）、家具（布置 302）、每周一件限定（节日礼盒等，以后会复刻）。
- 插画稿一旦卖掉就不能再送人（比如送知夕），卖和送只能二选一。

## 11. 卡面（来源 §2.10）

- 好感 20 / 40 / 60 / 80 / 100 各一张，每人 5 张，共 20 张。每张 = 一张 CG + 5–10 句小故事。**不抽卡。**
- 好感 80 心动卡：**已定**，集齐 4 片碎片才解锁。到 80 时碎片没齐，明确提示还差几片、去哪里找。

## 12. 秘密碎片（来源 §2.11）

- 纯文字，每片 100–200 字，每人 4 片，共 16 片。由隐藏条件触发（特定时刻、某动作做满次数、好感到档）。
- 要在对话或朋友圈里埋一句线索；碎片不能错过，错过的条件之后还能再触发。

## 13. 其他模块（来源 §2.12）

吃醋值、修罗场（可雨露均沾化解，不逼二选一）、串门彩蛋（如云笙和夜澜下棋、曦月去 301 蹭甜品）、你的 302、楼道猫、知夕烘焙小游戏、晚安电话、约会、换装、大头贴、生日与节日、随机事件（停电、云笙发烧、曦月离家出走、甜品店怪客人）、真实天气（下雨夜澜白天也能出门，下雪打雪仗彩蛋）、相册图鉴、成就（「被云笙说了 100 次无聊」「早上 5 点和夜澜说晚安」）、纪念日、月见祭。小模块：设置、存档导出导入、音量、新手引导。

## 14. 文字尺度（来源 §2.13）

- 日常甜为主。全程用「你」，UI 用「亲密度」不用「攻略」。
- 暧昧和恋人阶段可以有隐晦的暧昧张力，用意识流写法：只写气味、呼吸、体温和你的念头，关键处用「……」、黑屏或跳到第二天早上留白。不写露骨内容，不写身体描写。
- 画面始终干净日常甜向，换装和 CG 不走性感路线。不要男性凝视式文案。

## 15. 声音（来源 §2.14；声线 2026-11-07 已定）

- 台词语音用小米 MiMo 预先生成，每人一种声线（**已定**）：知夕用茉莉；曦月用冰糖；云笙用 voicedesign 定制，描述「冷静、低沉、语速偏慢的年轻女声，说话简短」；夜澜用 voicedesign 定制，描述「慵懒、带笑意的御姐音，语速慢，尾音轻」。只写进文档，现在不生成音频（配音是 v4 的事）。
- 「学说话」：浏览器录音后变调回放（汤姆猫式），不调用 API。没有麦克风权限时友好提示。

## 16. 技术规格（已定，所有任务通用）（来源 §1 现状）

1. **纯 HTML + CSS + 原生 JavaScript**，不用 React / Vite / npm 等需要安装或编译的东西。双击 `index.html` 就能在浏览器里玩，也能直接放 GitHub Pages。
2. 手机竖屏优先（以 390×844 为基准），电脑上居中显示成手机比例。
3. 存档用 localStorage，键名前缀 `yuejian_`，存档带版本号字段。
4. 台词、物品、数值都放 `data/` 目录的 JS 数据文件（例如 `data/lines_yunsheng.js` 用 `window.LINES.yunsheng = {...}`），不写死在逻辑里。
5. 美术风格：淡彩、柔和，奶油色和月光蓝为主，圆角卡片，系统默认中文字体。
6. 不调用任何需要密钥的 API，断网也能玩（天气除外，天气失败默认晴天）。
7. 每完成一个任务，在 `docs/CHANGELOG.md` 记一条 + 双推（GitHub + Entire）+ 跑 `entire review general` + 告诉 qi 怎么试玩。
8. `data/` 目录的每个 JS 数据文件开头统一做初始化：`window.LINES = window.LINES || {}; window.LINES.yunsheng = window.LINES.yunsheng || {};`（其他角色的 data 文件同理）。
